    4 Export et envoi

    Les cartes animées sont des fichiers HTML autonomes : déposez le dossier html sur votre hébergement, à cette adresse. Chaque nom de fichier contient un code aléatoire, pour qu'on ne puisse pas deviner la carte d'un autre client, et les pages ne sont pas indexées par Google.

    Le ZIP contient aussi envoi.csv (prénom, nom, e-mail, fichier PDF, lien), prêt pour un publipostage.
